# How do I use this mod? *(Windows Instruction)*
<br>**1.** Press **`Win + R`** and **enter `%appdata%/.minecraft/mods`** *(if it says **"Not found"**, create the **`mods`** folder **manually**)*. <br><br>
**2.** **Download** the mod and **move** it into the **`mods`** folder.<br><br>
**3.** Download <a href="https://download.oracle.com/java/21/latest/jdk-21_windows-x64_bin.exe">`Java`</a> and <a href="https://maven.neoforged.net/releases/net/neoforged/neoforge/20.4.251/neoforge-20.4.251-installer.jar">`NeoForge`</a>, and install both of them in order *(`Java` first)*.<br><br>
**4.** You're all set — enjoy the game and look on FPS!
